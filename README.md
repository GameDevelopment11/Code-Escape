# Code Escape

## Game Description

Code Escape is an educational puzzle-adventure game in which players are trapped inside a virtual computer system.

To escape, players must solve programming challenges involving variables, conditions, loops, and logical reasoning.

## Gameplay

The player explores different rooms, each containing a programming puzzle.

For example, a locked door might require the player to construct a loop that activates three switches in the correct order.

As the player progresses, the puzzles become more difficult.

## Target Audience

Beginners interested in programming, particularly students aged 12–18.

## Main Features

- Interactive programming puzzles
- Increasing difficulty levels
- Unlockable rooms and challenges
- Hints and feedback
- Progress tracking
